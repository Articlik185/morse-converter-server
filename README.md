**HTTP-сервис конвертации азбуки Морзе**

Учебный проект на Go: загрузка текстового файла через HTML-форму и преобразование текста в азбуку Морзе или обратно. Основан на задании Яндекс Практикума.

**Где смотреть реализацию**

[Ветка branch](https://github.com/Articlik185/morse-converter-server/tree/branch) — реализация сервера. [Учебный PR №1](https://github.com/Articlik185/morse-converter-server/pull/1) открыт. В main сохранена исходная заготовка.

**Как устроен проект**

- cmd/main.go — точка входа.
- internal/server — маршруты и настройки HTTP-сервера.
- internal/handlers — HTML-страница и обработка загрузки.
- internal/service — выбор направления преобразования.
- pkg/morse — функции преобразования.

**Запуск**

Установите Go версии не ниже указанной в go.mod. Команды выполняются из корня репозитория, чтобы сервер нашёл index.html:

    git switch branch
    go run ./cmd

Откройте http://localhost:8080/ и загрузите файл. Обработчик POST /upload ожидает multipart-поле myFile; результат возвращается в ответе и сохраняется в рабочем каталоге.

**Границы проекта**

Это учебный сервер для локального запуска. Ограничение памяти multipart-парсера не является ограничением размера загрузки; перед публичным размещением потребуются лимит тела запроса, проверка методов и более точные HTTP-коды ошибок.
